# MinhAnh Tool - GitHub Pages

Đây là bản web tĩnh gồm HTML/CSS/JavaScript.

## Chạy
Mở `index.html` trực tiếp hoặc đưa cả 3 file lên GitHub Pages.

## GitHub Pages
Repository cần có:
- index.html
- style.css
- app.js

Vào:
Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save

## Dữ liệu
Tài khoản và logs được lưu bằng localStorage trên chính trình duyệt đang sử dụng.
GitHub Pages không có backend/database dùng chung.

## Đăng nhập
Các nút đăng nhập chỉ mở URL chính thức cố định:
- Facebook
- Google
- YouTube
- Instagram

Không lưu mật khẩu, cookie hoặc thông tin xác thực.

## Nếu vẫn hiện "BypassTools - External"
Đó không phải giao diện của project này. Hãy thử:
1. Mở cửa sổ ẩn danh.
2. Tắt extension liên quan đến BypassTools/link redirect.
3. Gõ trực tiếp https://www.facebook.com/ vào thanh địa chỉ.

Nếu URL trực tiếp vẫn bị chuyển hướng, cần xử lý extension/phần mềm/trình duyệt trên máy.
